# robertamuri.github.io

Personal academic website of Roberta Muri: Ph.D. candidate in Economics at the University of Bologna and incoming Postdoctoral Research Associate at Caltech.

Static site (HTML/CSS/JS), served with GitHub Pages.

- `index.html`, `research.html`, `cv.html`, `teaching.html`, `news.html`: pages
- `assets/css/style.css`: styles
- `assets/js/news-data.js`: news items (edit this file to add news)
- `assets/files/RobertaMuri_CV.pdf`: CV shown on the CV page
